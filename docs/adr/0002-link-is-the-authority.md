# The link is the only authority

A Host opens a Gig from any browser without an account, and a Performer changes their own Tracks without an account. The Host link is the whole of the Host's authority over that Gig. The Performer link covers that one Performer only. Whoever holds it can add, rename, replace, remove, and download that Performer's Tracks. They cannot rename or remove the Performer. Signing in was the alternative, and it lost because the person at the venue often has nothing but the link. There is no list of Gigs to recover from. Losing the Host link loses the Gig.
